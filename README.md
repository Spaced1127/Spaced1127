## How I work

**Symptom first.** Hear the problem, reproduce it, find the actual fault, then write down what you did so the next person can follow it.

**Local-first by default.** No account if I can avoid it. No telemetry. If it needs a server, it should be your server.

**Vibecode, then verify.** Use every tool available, then check the work. The bench keeps me honest: the console either boots or it doesn't.
